# Coherence Hibernate Second Level Cache Core

This module contains no Java sources. It packages the shared
`hibernate-second-level-cache-config.xml` Coherence cache configuration used by
the Coherence Hibernate second-level cache implementations, so there is no API
documentation to generate.

This placeholder satisfies the Maven Central requirement that every artifact
with a packaging other than `pom` supplies a Javadoc JAR.

For the second-level cache API documentation, see
`com.oracle.coherence.hibernate:coherence-hibernate-cache-7`.

Project documentation: https://github.com/coherence-community/coherence-hibernate
